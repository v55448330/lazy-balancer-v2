# 行为研判与自动封禁 · 独立设计方案（归档备用，2026-09-25 用户提议并裁定：暂不实施）

> 状态：**设计归档，未实施**。与 XDP 前置防护（docs/xdp-prefilter-design.zh-CN.md）
> 相互独立——可单独立项、单独交付、单独开关；两案无依赖关系。
> 需求原点：根据请求行为自动判断恶意请求并自动封禁，维护自动封禁 IP 地址列表。

## 1. 前提与边界（诚实基线）

- **AI/LLM 不进请求热路径**：判定预算 82ns（@ipListFast）~µs（Caddy），
  LLM 推理百毫秒~秒级，差六个数量级——内联 AI 判分物理不成立。
  可行形态 = **近线研判管线**（批处理事件/日志 → 评分 → 自动封禁名单）。
- **AI 只是三层中的一层，且最不重要**：大部分价值由确定性启发式覆盖
  （重复拦截计数、错误率画像），ML/LLM 只处理边界灰区。对外文案不得
  把本能力包装成「AI 驱动」主卖点——主体是行为统计。

## 2. 三层研判管线

| 层 | 输入 | 方法 | 时延预算 | 产出 |
|---|---|---|---|---|
| L1 确定性启发式 | security_events + 访问日志计数 | 规则评分：N 分钟内被拦 X 次、403/404 比率、路径探测特征（/.env、/wp-admin 族）、扫描器 UA、威胁库命中复犯 | 秒级 | 直接封禁（高置信） |
| L2 行为统计画像 | 每 IP 滑动窗口特征（请求速率熵、路径多样性、错误率、间隔时序、方法分布） | 加权评分卡（纯 Go，可解释、无 GPU）；阈值以上进候选 | 分钟级 | 候选封禁集 |
| L3 LLM 研判（可选） | L2 灰区候选 + 证据摘要（采样请求头/路径，脱敏） | 用户自备 LLM API（OpenAI 兼容端点，密钥走现有配置面）；批量研判 | 分钟~小时级 | 灰区裁决（封/放/观察） |

L3 默认关；开启需用户显式配置端点+密钥+隐私确认（日志摘要外发声明）。

## 3. 自动封禁名单（与既有威胁情报库同构——本方案的最大杠杆）

- 新增系统级 IP 列表「**自动封禁名单**」（security_ip_lists，system=1，与
  中科大/FireHOL/ET 三个威胁源同机制）：条目带 `expires_at` 与 `confidence`，
  由研判管线写入；策略侧按现有「引用名单」机制一键引用，渲染走
  @ipListFast 投影，更新命中既有「名单变化且被引用才重载」门——
  **执行链零新增**。
- 开放协同（非依赖）：若 XDP 前置模块未来实施，同一名单可经其端口聚合
  模型灌内核 LPM trie——单一数据源供双执行面。

## 4. 安全护栏（误封是本项目最大的产品风险，全部硬性）

1. **dry-run 模式**：管线先以「建议封禁」运行（只记录不生效），用户在
   面板观察建议准确率后手动转正式——默认从 dry-run 起步。
2. **TTL 与衰减**：封禁必带过期（默认 24h，可配）；持续作恶续期、
   安静自动解封。
3. **保护名单**：信任名单、管理员最近登录 IP、内网段（RFC1918/ULA）
   永不被封。
4. **反馈环**：用户手动解封某 IP → 该 IP 进抑制清单（30 天不再自动封）；
   误封率统计进面板。
5. **审计留痕**：每次封/解封落审计日志（来源层 L1/L2/L3、置信度、证据
   摘要指针）。
6. **CDN/受信代理语义**：研判以真实 IP（受信代理还原后）为准——CDN 场景
   按回源 IP 封禁等于封 CDN 节点，strict 模式下伪造头不进特征。

## 5. 面板形态（若立项）

- 「安全防护 → IP 地址列表」新增系统名单卡「自动封禁名单」（只读查看+
  手动解封入口），同威胁情报库卡片族。
- 研判管线状态卡：dry-run/正式开关、今日建议/封禁/解封计数、误封反馈率。
- 配置面：L1 阈值、TTL、L3 端点与密钥（默认关）。

## 6. 里程碑

1. **B1**：L1 启发式 + 自动封禁名单 + dry-run + 护栏（无 AI，纯确定性；
   执行链复用现有名单机制——本体工作量最小）。
2. **B2**：L2 行为统计画像 + 误封反馈环面板。
3. **B3**：L3 LLM 研判（可选开关）+ 证据摘要脱敏管线。

## 7. 风险登记

| 风险 | 等级 | 缓解 |
|---|---|---|
| 误封合法用户（NAT 出口/运营商共享 IP/移动网络） | **高** | dry-run 默认 + TTL + 保护名单 + 反馈抑制（§4 全组） |
| LLM 成本与隐私（日志摘要外发） | 中 | L3 默认关+显式授权+脱敏；主打 L1/L2 |
| 自动封禁被滥用做反射（攻击者诱导封禁第三方 IP——X-Forwarded-For 伪造） | 中 | 研判只信受信代理还原链（strict 模式下伪造头不进特征） |
| 名单膨胀（自动封禁条目无界增长） | 低 | TTL 自然收敛 + 条目上限（超上限按置信度淘汰低分项） |
