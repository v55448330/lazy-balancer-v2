# 安全配置

## 请求处理链

```
入站 → 信任名单(阶段 0) → GeoIP 标签 → IP 预检(多策略合并) → 压缩(encode) → 请求体限制 → 限流 → WAF(CRS+自定义) → 反向代理
```

任一阶段拦截即刻返回配置的状态码与拦截页。

## 组件版本

| 组件 | 版本 |
|---|---|
| WAF 引擎 | Coraza v3 (coraza-caddy v2.6.1) |
| 规则集 | OWASP CRS v4.28.0 |
| GeoIP | IP2Region v3.17.0（中国省级，IPv4） |
| 限流 | caddy-ratelimit v0.1.0 |

> 地域规则仅对 IPv4 生效；IPv6 按「海外」处理（fail-closed）；IP 库未安装时地域规则不可启用。

## 安全策略

安全策略是独立实体，绑定到 HTTP 规则（一策略绑多规则，一规则最多绑 8 策略）。

| 设置 | 选项 |
|---|---|
| WAF 模式 | 关闭（全关）/ 仅自定义（CRS 不生效）/ 检测（仅记录）/ 拦截（达阈值 403） |
| 异常阈值 | 1/3/5/10/15/20（存量 0 值行:发射端按默认 5 执行,UI 列表显示 0——写路径已归一;导入通道的历史 0 行在下次重启时由启动归一回填 5(sync_security=1 从节点除外,以主节点快照为准)） |
| CRS 规则组 | 按攻击类型组加载/排除 |
| 自定义规则 | URI/args/headers/body/UA 多条件链式匹配 |
| IP 控制 | 白名单 / 黑名单 / 信任名单，CIDR，可引用 IP 列表 |
| 地域控制 | 拦截所选区域 / 仅允许所选区域 |
| 限流 | 按 IP 速率 + 突发 |
| 拦截响应 | 自定义 HTML + 状态码（离散值：400/401/403/404/503；限流拦截恒为 429，自动语义不在可选集） |

多策略绑定时，deny 侧 IP 控制合并为链首预检——被拒 IP 在任何规则评估前即被中断。

**信任名单语义（2026-09-15 裁定）**：信任 IP **全评估不拦截，检测事件全记录**（DetectionOnly）——策略层与多策略预检层两层一致；信任**仅豁免所属策略**（跨策略边界），其他策略引用同一信任地址列表即可共享信任；限流仍然生效。

**拦截页归因（按触发方，阶段化模型）**：规则配了阶段拦截页（阶段 1=IP 访问控制/地域拦截、阶段 3=WAF）时，对应阶段的全部拦截返回该规则的阶段页与状态码（引擎内以合成中断码 481/482 归因）；未配阶段页时按触发策略归因——每个绑定策略在引擎内分配独立合成中断码（483 起），返回该策略配置的拦截页与状态码；策略也未配页时回落默认 403（兜底归因边界）。多策略绑定无需再为归因统一拦截页配置。

## 安全事件

自动采集 WAF 拦截、IP ACL 拒绝、GeoIP 拦截。含趋势图、TOP 攻击类型/来源 IP（带地理位置）、一键加入策略名单。审计日志按大小轮转（默认 10MB × 5 份）。

## 规则集更新

CRS 和 IP2Region 支持手动/自动更新（失败自动回滚）。每次成功更新持久化规则树快照到数据卷，容器重建后自动恢复。

### 威胁情报库

内置三个只读情报源（USTC 黑 IP / FireHOL level1 / ET Compromised），条目聚合后写入 IP 地址列表中的三条 system 内置名单（只读，由更新任务维护）。

- **引用生效**：威胁名单无全局兜底规则——策略在「IP 访问控制」步骤引用对应内置名单才生效。内置名单仅允许黑名单（deny）模式引用；信任名单 / 白名单模式 / CRS 排除引用一律拒绝。
- **缺库降级**：CRS/IP2Region 库文件缺失时该节点安全链整体不渲染（IP 预检/ACL/限流/WAF/GeoIP 一并缺席），并告警提示补库（coraza Include 缺失文件会使整份配置被拒绝，负载均衡也会被拖死，故选择整体缺席）。威胁源单源失败仅影响该源，保留上次成功名单；引用空名单的策略其该名单拦截面为空。
- **更新排程**：任务级定时更新（星期多选 1=周一…7=周日 + HH:MM，默认每天 04:00，时区遵循基础设置的时区），自动更新总闸与逐源开关解耦；手动「立即更新」不受排程与开关影响。内容哈希未变化时跳过写入、不重载、不 bump 集群版本；单源失败按指数退避（1h→24h 封顶）重排，下个成功后回到排程节奏。
