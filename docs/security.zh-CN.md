# 安全配置

## 请求处理链

```
入站（受信代理开启时先还原真实客户端 IP） → 信任名单(阶段 0) → GeoIP 标签 → IP 预检(多策略合并) → 压缩(encode) → 请求体限制 → 限流 → WAF(CRS+自定义) → 反向代理
```

任一阶段拦截即刻返回配置的状态码与拦截页。

受信代理（CDN/前置代理回源）启用时，仅受信网段发来的代理头会被采信，还原后的真实客户端 IP 参与名单/地域/限流/事件判定；未启用或来源不在受信网段时一律按 TCP 源地址判定（fail-closed）。配置方式见[部署指南 · 受信代理](deployment.zh-CN.md#受信代理cdn-真实-ip-还原)。

## 安全事件采集（IPC + 兜底补采）

Caddy 审计写侧通过 Unix socket 把审计事务直接交给面板入库（DB commit 成功后 ack），正常路径不落全量 WAF 审计文件。

- 失败/超时/未确认：写入 `/app/data/security-events-spool` 的 fallback spool；
- 现有「安全事件采集」任务补采 spool；**DB commit 成功后才删除**已提交文件；
- 补采完成后 spool 为空；事件日志页显示「缓存 N 条」即待补采条目数；
- `security_events`（metrics DB）是成功事件的权威数据源，需配套数据库备份；spool 建议一并备份；
- 旧版 `audit.log` 升级后继续消费存量，消费完成后不再新增；
- socket/spool 路径可用 `LB_SECURITY_EVENTS_IPC_SOCKET`、`LB_SECURITY_EVENTS_SPOOL_DIR` 覆盖，Caddy 与面板必须指向同一数据卷。

| 限流 | caddy-ratelimit v0.1.0 |

> 地域规则仅对 IPv4 生效；IPv6 按「海外」处理（fail-closed）；IP 库未安装时地域规则不可启用。
>
> **两个版本口径并存是正常的**：镜像内置 xdb 是上表那个构建期固定下载（并校验 sha256）的版本，而运行期「IP 归属地库」自动更新取上游 `releases/latest`，更新后实际版本可能高于内置版。海外国家名中文表以 v3.18.0 xdb 的国家列为基线（238 个规范英文国名）；上游新增国名未收录时回退英文原名（优雅降级，不改变拦截语义）。
>
> **CRS 规则集同理**：上表的 v4.28.0 是镜像内置版本（构建期固定下载并校验 sha256），面板「规则集 → CRS 更新」手动或自动更新后会写入数据卷快照，实际生效版本可能更高（`/app/waf/crs/VERSION` 与面板显示为准）。渲染与拦截始终读运行期规则树，镜像内置版本只决定首次部署的起点。

## 安全策略

安全策略是独立实体，绑定到代理规则（一策略绑多规则，一规则最多绑 8 策略）。**协议边界**：阶段 0（信任名单）/ 阶段 1（IP 访问控制/地域拦截）策略可绑定 HTTP 与 TCP 规则；含限流（阶段 2）或 WAF（阶段 3）能力的策略仅可绑定 HTTP 规则（TCP 规则的拒绝动作=断连，无 429/WAF 引擎面）。

**策略类型**：策略按管辖阶段分为四类——阶段 0 · 信任名单 / 阶段 1 · IP 访问控制（黑白名单+地域+威胁库引用）/ 阶段 2 · 限流 / 阶段 3 · WAF；存量多阶段混合策略保留为「混合（兼容）」，可在策略页「更新迁移」拆分为单职子策略。**触发阶段四分类（事件页筛选与触发列）**：信任名单 / IP 访问控制（黑白名单+地域+威胁库合并口径）/ WAF（CRS 与自定义合并，具体规则在触发详情弹框内展示）/ 请求体异常。**攻击类型分布（安全总览）**：默认按阶段五桶展示（与触发阶段口径一致），取消「按阶段展示」勾选切换具体分类（SQL注入/XSS/扫描探测/自定义规则等）。

| 设置 | 选项 |
|---|---|
| WAF 模式 | 关闭（全关）/ 仅自定义（CRS 不生效）/ 检测（CRS 只记录，自定义规则仍按规则内动作执行）/ 拦截（达阈值 403） |
|异常阈值|1/3/5/10/15/20（写侧枚举校验；导入通道的历史 0 值行在下次重启时由启动归一回填 5（sync_security=1 从节点除外，以主节点快照为准）。发射端直读库值、无写死兜底：残留无效值（≤0，带外直写才会出现）渲染时显性报错（fail-visible），配置保存被拒绝 |
| CRS 规则组 | 按攻击类型组加载/排除 |
| 自定义规则 | URI/args/headers/body/UA 多条件匹配，可选同时满足（AND）或任一满足（OR） |
| IP 控制 | 白名单 / 黑名单 / 信任名单，CIDR，可引用 IP 列表 |
| 地域控制 | 拦截所选区域 / 仅允许所选区域 |
| 限流 | 按 IP 速率 + 突发 |
| 拦截响应 | 自定义 HTML + 状态码（离散值：400/401/403/404/503；限流拦截恒为 429，自动语义不在可选集） |

多策略绑定时，deny 侧 IP 控制合并为链首预检——被拒 IP 在任何规则评估前即被中断。**事件归因语义**：每个请求只落一条安全事件（同一请求被多个绑定策略的引擎各审一次时按请求归并，不会按策略数重复计数）；命中多个策略时按绑定顺序取第一条（policy_id ASC）记为归属策略——实际执行拦截的引擎实例在审计数据中不可恢复，归因是摄取期记账口径（安全事件页与策略 24h 计数同口径），不构成 forensic 判定。若同一请求先被检测策略记录、随后被拦截策略中断，事件结论按拦截改判（动作、触发规则、评分与归属策略一并取拦截策略的值）。归并以审计行携带的请求级标识为键：升级前写入的历史审计行没有该标识，按原样逐条入库。

**处理耗时展示限制**：拦截类事件的处理耗时由链最外层的计时收尾在审计记录落盘后补写，写入侧限时等待该终态；极端调度窗口（宿主机 CPU 抢占、GC 停顿）下等待可能超时，此时事件详情「处理时长」显示为空——仅影响该条事件的耗时展示，拦截行为与事件记录本身不受影响，后续事件照常显示。

**信任名单语义**：阶段 0 信任策略的「保留检测记录」开关决定处理方式：**关闭（默认，`trust_detection=0`）**时，命中任一绑定直通策略信任名单的 IP 直接转发上游，跳过 IP 预检、压缩、请求体限额、限流与 WAF 等后续安全流程，不产生安全事件；**开启（`trust_detection=1`）**时，信任 IP 在预检与该规则绑定的每个策略引擎中均按 DetectionOnly 仅记录、不拦截，限流仍然生效。阶段 0 信任按规则绑定生效；其他策略可引用同一信任地址列表。**TCP 规则语义一致**：直通模式连接直达上游、零安全事件；保留检测模式连接产「IP 信任名单检测」安全事件（动作=检测）后直达上游、不拦截（检测信任命中优先于阶段 1 全部名单/地域判定）；规则开启 PROXY protocol 时事件归因与发往上游的 PROXY 头均按还原后的真实客户端地址。

**拦截页归因（按触发方，阶段化模型）**：规则配了阶段拦截页（阶段 1=IP 访问控制/地域拦截、阶段 3=WAF）时，对应阶段的全部拦截返回该规则的阶段页与状态码（引擎内以合成中断码 481/482 归因）；未配阶段页时按触发策略归因——每个绑定策略在引擎内分配独立合成中断码（483 起），返回该策略配置的拦截页与状态码；策略也未配页时回落默认 403（兜底归因边界）。多策略绑定无需再为归因统一拦截页配置。

## 爬虫豁免与爬虫地址库

搜索引擎与 AI 爬虫常从海外或异地机房回源。开启「地域控制 → 爬虫豁免」后，经验证为真实的爬虫可跳过该策略的地域拦截，避免把合法收录/抓取挡在门外。该开关要求策略的地域拦截处于启用形态（GeoIP 模式非「关闭」），且**只豁免地域拦截**——IP 黑/白/信任名单、WAF、限流仍全量生效。

**验证方式**（防 UA 伪造；任一环节失败的请求按普通访客继续地域判定，fail-closed）：

- **PTR 双跳（默认）**：User-Agent 命中引擎 → 反向解析客户端 IP，其 PTR 域名后缀须属该引擎官方域（机房 PTR 不匹配）→ 正向解析该 PTR 域名，结果须包含客户端 IP（防自配 PTR）。解析失败、超时或 DNS 并发额度耗尽均不放行。
- **官方 IP 段（360）**：360 官方声明不支持反查，按其公布的 IP 段验证（内置种子为其公布段的快照，共 5 条：`42.236.8.0/21`、`42.236.17.0/24`、`42.236.101.0/24`、`180.153.236.0/24`、`180.163.220.0/24`，随 `crawlerbot-update` 任务更新）；段快照缺失或为空时 fail-closed。
- **观察级引擎**：无官方爬虫页的厂商（如华为 PetalBot、DeepSeek、Kimi）按厂商域名验证，面板以「观察级」标注，误判风险高于官方声明引擎。

**伪装处理**：UA 声称是某引擎但验证失败时，内部标记 `X-LB-Crawler-Spoof`，预检按该策略的阶段拦截页/状态码拒绝（未配置时 403），并记录「搜索引擎爬虫伪装」安全事件。伪装拒绝只覆盖本策略勾选的引擎集合（只勾 Google 的策略不会误拦验证失败的 Bing）。验证/伪装标记头由内部注入并在转发上游前无条件剥离，客户端伪造无效。

**引擎与默认值**：注册表含 Google、Bing、百度、搜狗、360、神马、DuckDuckGo、Yandex 及 OpenAI/Anthropic/Perplexity/字节等 AI 爬虫共 15 个引擎；新建策略默认勾选 Google/Bing/百度，AI 爬虫默认不勾选，按需开启。

**爬虫地址库**：`crawlerbot-update` 任务（主节点执行，从节点随集群快照同步）定时拉取 Google/OpenAI/Bing/360 官方源，原子写入 IP 地址列表中的只读系统名单「xxx 官方爬虫 IP」，并生成 `.fast` 预编译加速。默认每天 04:00 自动更新，可在「规则集 → 爬虫地址库」关闭总闸、调整排程或手动立即更新；内容未变时跳过写入，单源失败保留上次成功快照。

## 安全事件

自动采集 WAF 拦截、IP ACL 拒绝、GeoIP 拦截。含趋势图、TOP 攻击类型/来源 IP（带地理位置）。**IP 处置入口**：点击事件列表中的 IP 地址打开快捷弹框——按策略卡单击完成拦截/放行/信任（自动解析既有列表，无同侧列表时自动创建「{策略名}-黑名单/-白名单/-信任」并关联加入）；触发阶段链接打开触发详情弹框（纯信息展示，零操作）。审计日志按大小轮转（默认 10MB × 5 份）。

## 规则集更新

CRS 和 IP2Region 支持手动/自动更新（失败自动回滚）。每次成功更新持久化规则树快照到数据卷，容器重建后自动恢复。


### 自动封禁

面板提供基于阈值计数的自动封禁（默认观察模式，不直接封禁）：

- **开关**：安全事件页「自动封禁」状态卡；关闭后不再新增封禁条目，已有名单保留。
- **判定**：在配置时间窗内，同一来源 IP 符合统计口径的安全事件达到阈值后进入自动封禁名单。统计口径三选一：全部事件（默认）/ 仅拦截 / 仅检测；另可配置封禁时长（10 分钟至永久）。
- **观察模式**：默认开启，只记录候选与状态，不写入执行名单；确认误封率可接受后关闭观察模式。
- **生效条件**：自动封禁名单必须被安全策略的「IP 访问控制」以黑名单（deny）模式引用才生效；未被引用时名单只可见、不拦截。
- **与威胁情报库的区别**：威胁情报库是外部只读源；自动封禁是本地行为计数产生的系统名单，二者都在 IP 地址列表中展示，但数据来源与更新任务不同。

### 威胁情报库

内置三个只读情报源（USTC 黑 IP / FireHOL level1 / ET Compromised），条目聚合后写入 IP 地址列表中的三条 system 内置名单（只读，由更新任务维护）。

- **引用生效**：威胁名单无全局兜底规则——策略在「IP 访问控制」步骤引用对应内置名单才生效。内置名单仅允许黑名单（deny）模式引用；信任名单 / 白名单模式 / CRS 排除引用一律拒绝。
- **缺库降级**：CRS/IP2Region 库文件缺失时该节点安全链整体不渲染（IP 预检/ACL/限流/WAF/GeoIP 一并缺席），并告警提示补库（coraza Include 缺失文件会使整份配置被拒绝，负载均衡也会被拖死，故选择整体缺席）。威胁源单源失败仅影响该源，保留上次成功名单；引用空名单的策略其该名单拦截面为空。
- **更新排程**：任务级定时更新（星期多选 1=周一…7=周日 + HH:MM，默认每天 04:00，时区遵循基础设置的时区），自动更新总闸与逐源开关解耦；手动「立即更新」不受排程与开关影响。内容哈希未变化时跳过写入、不 bump 集群版本；内容有变化时名单文件直接热生效（约 1 秒内，无需重载面板或中断流量）；单源失败的重试在本次更新任务内完成；重试耗尽后不再按 1h→24h 额外退避，下一次自动运行时间仍按排程槽维护（空槽或过期槽推进到下一槽，已有未来槽不回拨）。
